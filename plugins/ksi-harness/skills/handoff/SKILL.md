`/clear`나 새 세션으로 넘어가기 전에, 지금까지의 대화를 새 에이전트가 바로 이어받을 수 있는 문서로 압축한다. compaction의 손실 요약에 기대지 않고 명시적으로 남기는 자리 — `goals`(`.ksi/`, 크로스세션·증거게이트)나 `TaskCreate`(세션 내 진행상황)로 이미 추적되는 게 없을 때, 혹은 그것만으로는 안 잡히는 대화의 맥락(막힌 이유·버린 접근·사용자가 강조한 것)을 넘길 때 쓴다.

## 저장 위치

작업 디렉터리가 아니라 스크래치패드(세션에 지정된 임시 디렉터리, 없으면 OS temp)에 저장한다 — 프로젝트 repo를 핸드오프 문서로 어지럽히지 않는다.

## 담을 것

- 지금까지 뭘 했고, 왜 그렇게 했는지(결과가 아니라 판단 근거)
- 막힌 것 / 시도했다 버린 접근과 이유
- 다음 세션이 바로 이어받을 수 있는 다음 행동
- **"제안 스킬" 절** — 다음 세션이 이어받을 때 쓸 만한 스킬을 미리 짚어둔다

## 담지 않을 것

- 이미 다른 산출물(commit·diff·`.ksi/` 원장·이번 대화의 TaskCreate 항목)에 있는 내용 — 복제하지 말고 경로·ID로 참조한다.
- API 키·비밀번호·개인정보 등 민감정보 — 전부 지운다.

인자로 "다음 세션에서 뭘 할 건지"가 왔으면 그 초점에 맞춰 문서를 구성한다.
